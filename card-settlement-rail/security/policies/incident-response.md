# Incident Response Policy

1. Detect and assign severity; P0 includes suspected unauthorized movement of funds or key compromise.
2. Freeze affected money movement before investigating when safe to do so.
3. Preserve logs, audit IDs, transaction IDs, hashes, and chain receipts.
4. Revoke/rotate compromised credentials; never paste secrets into incident channels.
5. Reconcile ledger, clearing files, queue state, and on-chain state before recovery.
6. Communicate with security, compliance, and accountable engineering owners.
7. Document root cause, impact, controls, timeline, and corrective actions.

Financial incidents require an explicit release gate before resuming settlement.
